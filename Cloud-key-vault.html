Secure Cloud Data Architecture using Azure Key Vault

This project demonstrates how I designed and implemented a secure cloud data architecture using Azure Key Vault, customer-managed encryption keys, and Always Encrypted to protect sensitive application data.

Problem

Cloud databases are often readable by administrators and attackers. I built a system where even the cloud provider cannot read the data.

Solution

The solution uses Azure Key Vault, Azure Active Directory and Always Encrypted so that encryption keys never live in the database.

Security Controls

  • Azure Key Vault for key management
  • Customer-managed encryption keys
  • Always Encrypted on SQL columns
  • Identity-based access control
